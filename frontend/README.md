# AMBE MARKETING Website

React + Vite website for AMBE MARKETING.

## Local preview

```bash
npm install
npm run dev
```

Then open the localhost address shown by Vite.

## Easy catalogue updates

Product categories and descriptions: `src/data/products.ts`

Product/category images: `public/products/`

Complete AMBE catalogue: `public/catalogue/ambe-catalogue.jpg`

Logo/favicon: `public/ambe-logo.png`

Replace an image with a new file using the same filename and the page will use it without component changes.

## Deployment

Do not deploy until the local preview is reviewed and approved.
